# UDCタイマー / プレゼンタイマー Ver.3

学会・講演・口頭発表などで、発表時間とベルの鳴動時刻を管理するタイマーです。**使いたい版を選んでください。** 通常の利用にプログラミングやソースコードのダウンロードは必要ありません。

## まず使ってみる（ブラウザで開くだけ）

| 種類 | こんな方に | 起動方法 |
| --- | --- | --- |
| **UDCタイマー：ブラウザ版** | Windows・Mac・タブレット等のブラウザで使いたい | **[ブラウザ版を開く](https://yo-1.github.io/udc-presentation-timer/web/)** |
| **UDCタイマー：PWA版** | iPadのホーム画面に追加したい、オフラインでも使いたい | **[PWA版を開く](https://yo-1.github.io/udc-presentation-timer/pwa/)** |
| **プレゼンタイマー：Windows EXE版** | Windowsで独立したアプリとして使いたい | **安全性確認中につき正式配布を保留** |

**ブラウザ版もPWA版も、リンクをクリックするだけで動作します。** GitHubの「Code → Download ZIP」や `index.html` の手動ダウンロードは不要です。

### ブラウザ版の使い方

1. **[ブラウザ版を開く](https://yo-1.github.io/udc-presentation-timer/web/)** をクリックします。
2. 「発表時間」と「ベル設定」を必要に応じて変更し、「設定反映」を押します。
3. 「開始」で計時、「停止」で一時停止、「リセット」で初期状態に戻します。
4. 各ベルの「試聴」で音を確認できます。現在の仕様ではベルがOFFのときは試聴音も鳴りません。
5. 設定を次回も使う場合は「設定保存」を押します。発表時は「フルスクリーン」を利用できます。

**注意：** ベルを鳴らすため、使用前に端末の音量・音声出力先を確認し、試聴してください。

### PWA版の使い方・ブラウザ版との違い

**[PWA版を開く](https://yo-1.github.io/udc-presentation-timer/pwa/)** だけで、ブラウザ版と同様にタイマーを利用できます。**iPad専用ではありません。** PCのブラウザから開いても使用できます。

PWA（Progressive Web App）版を分けている理由は、iPadなどでホーム画面に追加し、通常のアプリに近い形で起動・オフライン利用できるようにするためです。

iPadでホーム画面に追加する場合：

1. iPadの **Safari** でPWA版のリンクを開きます。
2. Safariの共有メニューから **「ホーム画面に追加」** を選びます（iPadOSのバージョンにより表示は異なります）。
3. ホーム画面に追加されたアイコンから起動します。

iPad実機では、ホーム画面への追加、オフラインでの画面表示・開始/停止/リセット・ベル試聴を確認済みです。ただし初回はインターネットに接続して開く必要があります。オフラインでの利用は、事前の読み込み状態や端末のキャッシュ管理に左右される場合があります。

### Windows EXE版：プレゼンタイマー Ver.3

Windows用の実行ファイル（`PresentationTimer.exe`）です。**Pythonのインストールやソースコードのダウンロードなしで使うことを想定した版**です。UDCロゴを使用しない汎用的な画面で、ブラウザ版・PWA版とはデザインが異なります。

**現在は正式配布を保留しています。** 試験用EXEについて、Windows SmartScreenの警告とウイルスバスターの検出報告があり、安全性を調査中です。検出を無視した実行やセキュリティ製品の除外設定は推奨しません。調査・検証が完了した後に、正式なダウンロード方法を案内します。

## 主な機能

- ベル1：1回、ベル2：2回、ベル3：3回、ベル4：8回
- 各ベルのON/OFFと時刻設定（0分0秒の指定にも対応）
- ベル音の試聴と音量調整
- 残り時間・経過時間の表示、開始・停止・リセット
- 設定保存、フルスクリーン表示
- UDCロゴ・UDCカラー（ブラウザ版・PWA版）

## 開発者向け：ソースコードの構成

ここからは改修・ビルドを行う方向けの説明です。通常の利用者は読む必要はありません。

- `web/index.html`：ブラウザ版のHTMLソース。公開URLの `/web/` はこのファイルを表示します。
- `pwa/`：PWA版のソース、マニフェスト、サービスワーカー、アイコン
- `windows/udc_timer.py`：Windows版のPythonソース
- `windows/build_exe.bat`：開発者向けローカルEXEビルドスクリプト
- `.github/workflows/windows-build.yml`：GitHub ActionsでのWindows EXE生成
- `assets/`：画像・ベル音
- `tests/`：構造確認用テスト

開発者向けビルド成果物名：`PresentationTimer_Windows`、EXE名：`PresentationTimer.exe`。既存のWindows版設定との互換性のため、設定保存先の旧フォルダ名は維持しています。
